# Car Diagnosis — Workshop RC2 (команда «Резонанс», ID 56471)

Это **следующая версия для проверки**, а не финальная 1.0. Ассистент не запускал Unity: проект не компилировался,
сцена не генерировалась и не рендерилась, тесты Unity не запускались. Что проверено статически — в `KNOWN_ISSUES.md`.

## Требования
Unity **6000.3.28f1**, Windows. URP 17.3.0, Input System 1.20.1 (из `Packages/manifest.json`, версии не менялись).

## Запуск
1. Распаковать архив в **новую** папку (не поверх RC1 и не поверх резервной копии).
2. Unity Hub → Add → Add project from disk → папка, где лежат `Assets`, `Packages`, `ProjectSettings`. Открыть в 6000.3.28f1.
3. Дождаться импорта. В Console не должно быть красных ошибок. Если есть — пришлите первую ошибку целиком.
4. Меню **Tools > Diagnoz > Create Workshop Scene (RC2)**.
   - Первый запуск создаёт `Assets/Diagnoz/Generated/Workshop_RC2/Diagnoz_Workshop.unity` (+ материалы, меши, текстуры в той же папке)
     и, если их ещё нет, настройки URP в `Assets/Diagnoz/Generated/Rendering_RC2`.
   - Повторный запуск спрашивает: **Открыть** (ничего не меняет), **Отмена**, **Пересоздать** (удаляет только папку `Workshop_RC2`
     и собирает её заново; объекты не дублируются, модель, шрифт, каталог и скрипты не трогаются).
   - Сцена ставится первой в Build Settings. Ничего вручную расставлять не нужно.
5. Открыть сцену (генератор открывает её сам) → **Play**. Окно Game: 1920×1080 или 1280×720.
6. Тесты: **Window > General > Test Runner > EditMode > Run All** (сборка `CarDiagnosis.Core.Tests`, 44 теста).

Старый пункт меню RC1 «Create Complete Scene» удалён: новый генератор его заменяет. Старые сцены RC1 в этом проекте не нужны.
