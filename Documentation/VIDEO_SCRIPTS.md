# Сценарии видео «Car Diagnosis»

Требования шаблона: 3 обязательных видео; общая длительность — до 240 с (допуск +1 с на ролик, итого до 243 с); ускорение содержательной части — не более ×1,5, пропусков — до ×10; все видео — в одной папке Google Диска, ссылка на папку — на слайде 1.

Запись: окно Game 1920×1080, без монтажа интерфейса; курсор виден.

## 1. Core Loop — ~60 с

- **Показать:** заказ 01, выбор узла и проверки, наблюдение.
- **Действия:** 0–8 с — панель жалобы. 8–20 с — вращение камеры, ЛКМ по генератору (подсветка), «Осмотр контактов» → «отклонений нет». 20–40 с — ЛКМ по аккумулятору → «Мультиметр» → окно 10,5 В и ориентир 12,6 В. 40–60 с — «Осмотр контактов» на аккумуляторе → «клеммы чистые»; показать время 35 из 50.
- **Подтверждает:** цикл «узел → проверка → наблюдение → вывод», цену проверок.
- **Должно быть видно:** подсветку, крупное показание, ориентир, уменьшение времени.

## 2. Game Loop — ~80 с

- **Показать:** заказ 02, выбор ремонта, неверный ремонт и исправление.
- **Действия:** 0–10 с — жалоба «Заводится через раз». 10–25 с — мультиметр → 12,6 В (норма). 25–40 с — «Заменить аккумулятор» с окном цены (−20 мин) → контрольная проверка → «Завершить» → «Клиент вернулся». 40–50 с — «Повторить заказ», время снова 50. 50–80 с — осмотр → налёт → «Очистить клеммы» → осмотр → чисто → «Завершить» → «Заказ выполнен».
- **Подтверждает:** точку выбора, ресурс времени, штраф за неверный ремонт, контрольную проверку.
- **Должно быть видно:** цену до подтверждения, итог провала и успеха.

## 3. User Flow — ~90 с

- **Показать:** полный путь сессии от запуска до возврата к первому заказу.
- **Действия:** 0–5 с — нажатие Play, сцена гаража. 5–40 с — заказ 01 правильно (мультиметр → замена → проверка → завершить), экран итога с временем. 40–45 с — «Следующий заказ», шапка «ЗАКАЗ 02 ИЗ 02». 45–75 с — заказ 02 правильно, итог «Все учебные заказы пройдены». 75–85 с — «К первому заказу». 85–90 с — (опционально, ускорение до ×10) ветка «Время заказа вышло».
- **Подтверждает:** переходы между заказами, открытие следующего случая, повтор.
- **Должно быть видно:** экраны итога, номер заказа, сброс времени.

Итого: ~230 с.

## Скриншоты из этих записей

1. Машина в гараже, выбран аккумулятор (слайд 2 — ключевой кадр).
2. Окно мультиметра 10,5 В с ориентиром (слайд 7).
3. Окно подтверждения ремонта с ценой (слайд 8).
4. Экран «Клиент вернулся» (слайды 8, 12).
5. Экран «Заказ выполнен» с временем (слайд 9).
6. Панель жалобы клиента (слайд 10).
