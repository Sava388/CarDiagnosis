# Проверка RC2 за 15–20 минут

Отмечайте «да / нет». На каждое «нет» — короткая запись: что делали, что увидели, первая ошибка Console (если есть).

## 1. Открытие и компиляция (2 мин)
- [ ] Проект открылся в 6000.3.28f1, версия Unity и пакеты не предлагают обновление.
- [ ] После импорта в Console нет красных ошибок.
- [ ] Test Runner > EditMode > Run All: 44 теста, все зелёные.

## 2. Генерация сцены (2 мин)
- [ ] Tools > Diagnoz > Create Workshop Scene (RC2) — окно «Создана и сохранена сцена…».
- [ ] В Console нет ошибок; допустимы только жёлтые предупреждения «Diagnoz: точка … может быть недоступна» — пришлите их текст.
- [ ] Повторный запуск → «Пересоздать»: сцена пересобрана, в Hierarchy один `Diagnoz_Workshop`, одна `Main Camera`, одно колесо `Wheel_L_Front`.
- [ ] Повторный запуск → «Открыть»: открылась та же сцена без изменений.

## 3. Внешний вид (3 мин) — Play, не трогая управление, затем пройтись
- [ ] Нет розовых (missing) материалов.
- [ ] Небольшая мастерская: ворота спереди, дверь сзади, балки и светильники на потолке, плинтус и двухцветные стены.
- [ ] Зоны различимы: машина на посту с подъёмником; верстак у задней стены; шиномонтаж и балансировка слева; стеллаж, колёса и шкаф справа.
- [ ] Машина: стёкла тёмные полупрозрачные, видны фары, решётка, бамперы, арки, диски с шинами, ручки, зеркала.
- [ ] Свет тёплый, тени есть, не пересвечено и не слишком темно; нет сильного свечения.
- [ ] Запасные колёса на стойке выглядят так же, как колёса машины.
Если картинка в чём-то плохая — скриншот Game 1920×1080 с места появления.

## 4. Движение и меню (2 мин)
- [ ] WASD + мышь работают, Shift ускоряет. Нельзя пройти сквозь машину, стены, ворота, дверь, станки, верстак, стеллажи.
- [ ] При появлении игрок не застрял, под пол не проваливается.
- [ ] Esc — меню паузы: курсор появился, камера не вертится, ходьба стоит. «Продолжить» возвращает управление.
- [ ] Подсказка «[E] …» появляется только когда смотришь на точку вблизи; через машину с другой стороны не появляется.

## 5. Старые диагностические заказы (4 мин)
Решения: 1 — Аккумулятор: «Мультиметр» (10,5 В) → «Заменить аккумулятор» → «Мультиметр»;
2 — Аккумулятор: «Осмотр контактов» → «Очистить клеммы» → «Мультиметр»; 3 — Генератор: «Мультиметр» → «Заменить генератор» → «Мультиметр»;
4 — Двигатель: «Осмотр контактов» → «Зачистить массу» → «Мультиметр».
- [ ] Подойти к капоту, E → режим осмотра: курсор свободен, ПКМ вращает, ЛКМ выбирает узел, панель узла справа.
- [ ] Esc/кнопка выходит из осмотра; в ходьбе панель узла и жалоба скрыты, машина не закрыта интерфейсом.
- [ ] Заказы 1–4 проходятся, результат и «Следующий заказ» работают как в RC1. Один раз сделайте неверный ремонт → «клиент вернётся» → «Повторить».

## 6. Новый заказ «Сезонный шиномонтаж» (4 мин)
- [ ] Карточка заказа показывает цель; подсказка ведёт по шагам.
- [ ] Переднее левое колесо, E → колесо снято, оно в руках (справа внизу экрана), под порогом появилась подставка.
- [ ] Шиномонтажный станок, E → колесо легло на стол; окно станка справа: «Демонтировать» → шина исчезла (голый диск), «Смонтировать: зимняя» → шина с крупным протектором, на табличке «Шина: зимняя».
- [ ] «Снять колесо со станка» → в руках. Балансировочный станок, E → колесо на валу.
- [ ] «Запустить станок» → вал крутится, на экране станка «25 г». Выбрать неверный груз → прогон → остаток, груз снят. Верный груз → прогон → «0 г OK».
- [ ] Снять колесо → к машине, E → установлено, E → проверка, окно «колесо закреплено, шина зимняя». Завершить → итог про **одно** колесо.

## 7. Перезапуск посреди переноса (1 мин)
- [ ] Повторить заказ: снять колесо, держать в руках → Esc → «Начать заказ заново». Колесо снова на машине, летняя шина, подставки нет, руки пусты, время полное.
- [ ] Положить колесо на станок → Esc → «Начать заказ заново»: на станке колеса нет, второе колесо не появилось.

## 8. Финал и новая смена (1 мин)
- [ ] После пятого заказа — «Итоги смены» с пятью строками. «Новая смена» → игрок у входа, заказ 1, колесо на машине, режим ходьбы.

## 9. Два разрешения (1 мин)
- [ ] Game 1280×720 и 1920×1080: карточка заказа, подсказка [E], индикатор «в руках», окна станков и результата не обрезаны,
  кириллица без квадратиков, кнопки не налезают друг на друга. Окно станка справа не закрывает станок и колесо.
