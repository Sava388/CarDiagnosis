# Управление (RC2)

## Мастерская (ходьба)
| Клавиша | Действие |
|---|---|
| W A S D | ходьба |
| Shift | быстрее |
| Мышь | обзор (курсор скрыт) |
| E | действие с точкой под прицелом — подсказка «[E] …» внизу экрана |
| Esc | меню паузы (продолжить / начать заказ заново / новая смена) |

Точки взаимодействия (одна клавиша E): капот машины — осмотр узлов; переднее левое колесо — снять / установить / проверить;
шиномонтажный станок; балансировочный станок. Дистанция — около 2,4 м, сквозь машину и стены точка не выбирается.

## Осмотр машины (диагностические заказы)
Вход: подойти к капоту, E. Курсор освобождается, ходьба и обзор мышью отключены.
| Клавиша | Действие |
|---|---|
| ЛКМ | выбрать узел |
| ПКМ + мышь | вращать камеру вокруг машины |
| Колесо мыши | приблизить / отдалить |
| Esc или кнопка «Выйти из осмотра» | вернуться к ходьбе |

## Окна
Когда открыто окно (заказ, итог, станок, пауза), курсор свободен, ходьба и обзор заблокированы, клики по миру не проходят.
Esc закрывает необязательные окна (станок, пауза); обязательные (результат, итоги) закрываются кнопками.
