# Известные ограничения и упрощения — Workshop RC2

## Что реально проверено (ассистентом, без Unity)
- Синтаксический разбор всех 21 файла C# (tree-sitter): 0 ошибок. **Это не компиляция**: типы, сигнатуры API Unity и ссылки между сборками компилятором не проверялись.
- Сверка вызовов между файлами (имена методов UI ↔ WorkshopDirector / WheelServiceView / WorkshopAudio / OrderFlow, ключи материалов генератора).
- Python-зеркало правил каталога, диагностики и шиномонтажа (`StaticChecks_Python/catalog_mirror.py`, `tire_mirror.py`):
  все каталоги-образцы проходят, все `invalid/*` отклоняются; верный путь шиномонтажа 38 из 50 мин; перебор 3043 состояний колеса —
  колесо всегда в одном месте, успех только при новой шине и балансировке. **Это модель на Python, а не запуск C#.**
- Поиск неподдерживаемых символов в строках C# и JSON (`glyph_scan.py`): 0 проблем (папка Tests пропускается: там намеренный `→` для теста отсутствующего глифа).
- Арифметика раскладки UI на холсте 1440×810 (`layout_check.py`): нет пересечений панелей, кнопки окон не налезают на текст. **Это расчёт, а не рендер.**
- `.meta`: у каждого файла и папки в Assets есть .meta, сирот и повторяющихся GUID нет, GUID файлов RC1 сохранены.

## Что не проверено и требует запуска Unity пользователем
- Компиляция, EditMode-тесты, работа генератора, итоговый вид сцены, свет и тени, производительность, звук.
- Доступность точек E с реальных мест (генератор пишет предупреждение, если луч с типового места не доходит).
- Раскладка UI в 1280×720 и 1920×1080 на реальном экране.

## Упрощения (сознательно)
- Обслуживается **одно** колесо (переднее левое). Остальные три — декоративные и не снимаются.
- Колесо переставляется между точками мгновенно, без анимации рук, болтов и домкрата; под порог ставится подставка.
- Шиномонтаж и балансировка — игровая модель, а не инструкция: два шага на станке, замер, выбор груза, контрольный прогон.
- Ворота и дверь не открываются, подъёмник не поднимается.
- Освещение только realtime, без запекания; зонд отражений рендерится один раз при старте.
- Звуки синтезированы кодом — это набор сигналов, а не законченный саунд-дизайн.
- Машина — стилизованная модель из примитивов без салона и двигателя в деталях; не копия реального автомобиля.

## Возможные проблемы, на которые стоит посмотреть в первую очередь
- Колесо в руках прикреплено к камере: у стены оно может частично войти в стену (только визуально).
- Если в вашей версии TMP нет свойства `textWrappingMode` (появилось в uGUI 2.0), будет ошибка компиляции в генераторе — пришлите её.
- Пересоздание удаляет папку `Assets/Diagnoz/Generated/Workshop_RC2` целиком: не храните там свои файлы.
- Каталог `orders.json` из RC1 (4 заказа без шиномонтажа) работает, но тогда новый заказ не появится — это ожидаемо.
