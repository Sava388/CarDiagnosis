# Проверка RC1 за 15–20 минут (выполняет Савелий Захаров в Unity 6000.3.28f1)

Записывайте номер шага и что пошло не так. Скриншот Console при любой красной ошибке.

## 0. Импорт (3–5 мин)
1. Открыть распакованный проект. **Console: нет красных ошибок компиляции?**
2. Window > General > Test Runner > EditMode > Run All. **Сколько зелёных из 30? Имена красных.**
3. Tools > Diagnoz > Create Complete Scene → открыть новую `Diagnoz_Start.unity`.

## 1. Старт (1 мин)
4. Play. Должно открыться окно «Смена в мастерской» с целью игры и управлением, кнопка «Начать смену».
5. Пока окно открыто, клики по машине ничего не выбирают. Нажать «Начать смену» → «ЗАКАЗ 01 ИЗ 04».

## 2. Заказ 1 «Машина не заводится» (2 мин)
6. Правая панель: кнопки «Мультиметр · 5 мин», «Осмотр контактов · 5 мин», «Заменить аккумулятор · 20 мин», «Очистить клеммы · 15 мин», «Заменить генератор · 25 мин», «Зачистить массу · 15 мин», «Завершить заказ». Текст не обрезан, кнопки не налезают друг на друга и на нижнюю панель.
7. Клик по кнопкам панели не меняет выбор узла за панелью.
8. Выбрать аккумулятор → Мультиметр → «10,5 В». **Неверный ремонт:** «Очистить клеммы» → Мультиметр → Завершить → «Клиент вернулся» → «Повторить заказ»: время снова 50 из 50.
9. Мультиметр → «Заменить аккумулятор» → «Завершить» недоступно до проверки → Мультиметр «12,6 В» → Завершить → «Заказ выполнен» → «Следующий заказ».

## 3. Заказ 2 «Заводится через раз» (1 мин)
10. Аккумулятор → Осмотр контактов → «Налёт на клеммах» → Очистить клеммы → Осмотр → Завершить → успех.

## 4. Заказ 3 «Горит лампа зарядки» (2 мин)
11. Аккумулятор → Мультиметр «12,2 В». Генератор → Мультиметр «12,3 В» (ориентир 13,8-14,5 В), Осмотр — «Внешне в порядке».
12. Выбрать генератор → «Заменить генератор» → Мультиметр «14,1 В» → Завершить → успех.
    Можно проверить ошибку: замена аккумулятора здесь не помогает (после неё снова 12,2 В).

## 5. Заказ 4 «Снова щёлкает стартер» (2 мин)
13. Аккумулятор: Мультиметр «12,6 В», Осмотр «Клеммы в порядке» — причина не в нём.
14. Двигатель → Осмотр → «Окисленная масса» → «Зачистить массу» → Осмотр → Завершить → успех → «Итоги смены».

## 6. Финал и рестарт (1 мин)
15. Окно «Смена закончена»: четыре строки (время, попытки), «Выполнено заказов: 4 из 4».
16. «Начать заново» → стартовое окно → «Начать смену» → снова «ЗАКАЗ 01 ИЗ 04», 50 мин.

## 7. Время (1 мин)
17. В заказе 1 нажимать Мультиметр на аккумуляторе подряд (закрывая окно). После 7-го замера остаётся 15 мин — меньше, чем самый дешёвый ремонт с контролем (20) — и открывается «Время заказа вышло». «Повторить заказ» снова даёт 50 мин.

## 8. Данные (3–4 мин, Play остановлен)
18. Скопировать `CatalogExamples/orders_extended.json` поверх `Assets/StreamingAssets/CarDiagnosis/orders.json` → Play → «ЗАКАЗ 01 ИЗ 05»; пройти до заказа 5 «После долгой стоянки» (35 мин) и завершить.
19. Скопировать `CatalogExamples/invalid/duplicate_order_id.json` поверх `orders.json` → Play: в Console красная ошибка «повторяющийся id», на стартовом окне «Резервный каталог», игра с 4 заказами.
20. Вернуть исходный: скопировать `CatalogExamples/orders_base.json` поверх `orders.json`.

## 9. Разрешения (1 мин)
21. Game view 1280×720 и 1920×1080: панели не перекрываются, тексты читаются, окно по центру.

Необязательно: File > Build Profiles > Windows > Build — проверить, что рядом с exe есть `<Имя>_Data/StreamingAssets/CarDiagnosis/orders.json`, и игра запускается.
