# Изменения 1.0 RC1 (относительно версии, проверенной 20.11.2026)

## Данные
- Все заказы, стоимости действий, тексты наблюдений, стартового и финального экранов вынесены в `Assets/StreamingAssets/CarDiagnosis/orders.json`.
- Добавлен встроенный резервный каталог `Assets/Diagnoz/Resources/CarDiagnosis/DefaultCatalog.json` (идентичен основному).
- Два прежних заказа перенесены без изменения поведения: те же тексты, 10,5 В / 12,6 В, стоимости 5 / 5 / 20 / 15 мин, бюджет 50 мин.
- Новые заказы: 3 «Горит лампа зарядки» (генератор не заряжает), 4 «Снова щёлкает стартер» (окисленная масса двигателя — жалоба похожа на заказ 2, но клеммы и напряжение в норме).
- Новые ремонты: «Заменить генератор» (25 мин, узел Генератор), «Зачистить массу» (15 мин, узел Двигатель).

## Код
- Новое ядро `CarDiagnosis.Core` (отдельная asmdef): `CatalogData`, `CatalogValidator`, `CatalogLoader`, `DiagnosisRules`, `OrderFlow`.
- `BatteryOrderSession` — теперь только загрузка/проверка каталога и хранение `OrderFlow`. Имя, `Configure(definition, node)` и GUID сохранены. Старые enum (`CheckType`, `RepairType`, `FaultCause`) и `OrderCase` удалены.
- `BatteryOrderUI` — правил больше не содержит; кнопки проверок и ремонтов создаются из каталога при запуске. Сигнатура `Build(...)` и GUID сохранены. Добавлены окна: стартовое, итог заказа (было), финал смены, «Начать заново», ошибка данных.
- `DiagnosticNode` — добавлено свойство `Id` (`battery`, `alternator`, `engine`, `brakes`; поле `nodeId` можно задать вручную). Генератор не менялся.
- Ремонт теперь разрешён на любом узле, для которого он указан в каталоге (раньше — только на аккумуляторе). Контрольная проверка засчитывается только на отремонтированном узле (раньше — любая проверка аккумулятора; для заказов 1–2 это одно и то же).
- Порог «время вышло» теперь считается от минимальных стоимостей в каталоге (прежде — из констант; для заказов 1–2 значения те же: 20 и 5 мин).
- После последнего заказа вместо возврата к первому открывается финальный экран; «Начать заново» возвращает на стартовый экран.

## Интерфейс
- Панель подсказок управления сужена с 1120 до 700 единиц, чтобы удлинённая правая панель (до 7 действий) её не перекрывала. Тексты управления и предупреждения берутся из каталога.
- Заголовок: «CAR DIAGNOSIS / МАСТЕРСКАЯ» (из каталога). Камера, модель, подсветка, URP не менялись.
